# Sound Identifier (Name WIP)
A device that hears sounds and finds their phonetic identity!

### UPDATE THIS UPDATE THIS UPDATE THIS

It will use a neural network trained on sounds to find what phonetic sound you're making! It'll have all the sounds, like /b/, /θ/, and /ɬ/ǃ
Don't worry, if IPA's not your thing, it can write it in other systems too.
In English, a /ʒ/ might be a "zh", where as in French it'd simply be a "j".
In Russian, a /dʒ/, which would just be a "j" in English, could be a "дж".

I'll try to add as many modes as possible, but some languages just don't really have some sounds in them. For example, there's not *really* a way to write the /θ/, or "th" sound in some langauges as it's kind of a rare sound in the grand scheme of languages.
